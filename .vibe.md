## Agent tooling

### Structural edits (codemod MCP)

Deterministic multi-language edits via YAML recipes — preview then apply:

- Playbook: `.cursor/skills/codemod-mcp/reference.md`
- Human doc: `docs/codemod-mcp.md`
- Rust MCP: `cargo run -q --manifest-path rust/Cargo.toml -p codemod_recipe_host --bin codemod_mcp -- --workspace-root . --codemod-root .codemod`

Pair **codebase-memory** (locate → impact) with **codemod-mcp** (`preview_recipe` → `apply_recipe`).

## Project overview

**Name**: codemod_recipe  
**Purpose**: YAML recipe-driven codemods with a Rust tree-sitter engine, stdio host, MCP server, and VS Code extension  
**Primary languages**: Rust (runtime), TypeScript/Vue (extension)

## Layout

| Path | Role |
|------|------|
| `rust/` | Engine, YAML model, `codemod_host`, `codemod_mcp` |
| `vscode_extension/` | VS Code UI + bundled host binary |
| `.codemod/` | Shipped recipes, maps, templates |
| `test/fixtures/` | Rust integration/golden fixtures |
| `export/` | Bootstrap skills/rules copied into consumer projects |

## Recipes

Recipes require `id` and `steps`. Agent skill: `codemod-yaml-dsl` (under `export/.agents/skills/`).
