# What agents use

After `bootstrap_project`, agents get:

- Usage docs under `.agents/skills/codemod-recipe/docs/` (same pages as this `docs/usage/` tree)
- Thin **Architect** / **Builder** skill indexes that link into those docs
- An always-on rule pointing at the two modes

| Mode | Use for |
|------|---------|
| **Architect** | Create or modify recipes, components, queries, templates |
| **Builder** | Understand the workspace (intel) or apply registered recipes/components |

Prefer this guide and the topic docs when learning yourself.
